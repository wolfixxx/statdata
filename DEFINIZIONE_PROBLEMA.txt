B. Query builder (guidato)

Input umano:

{
  "source": "eurostat",
  "dataset": "namq_10_gdp",
  "filters": {
    "geo": "IT",
    "na_item": "B1GQ",
    "unit": "CLV05_MEUR",
    "s_adj": "CA",
    "freq": "Q"
  },
  "start": "2015",
  "end": "2024"
}


Il modulo:

valida filtri contro i codelist
